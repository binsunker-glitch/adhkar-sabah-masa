# موقع أذكار الصباح والمساء

موقع عربي جميل لأذكار الصباح والمساء من مصادر موثوقة (حصن المسلم، صحيح البخاري ومسلم، سنن أبي داود والترمذي).

## المميزات
- 🌅 أذكار الصباح + 🌙 أذكار المساء (20 ذكر لكل ورد)
- 🔁 مسبحة إلكترونية لكل ذكر مع حلقة تقدم
- 🌙 الوضع الليلي / ☀️ النهاري (يُحفظ)
- 🔠 تكبير وتصغير الخط العربي (14 - 30)
- 📱 متجاوب مع الجوال
- 📚 المصدر والفضل لكل ذكر

## التشغيل محلياً
افتح `index.html` مباشرة في المتصفح — لا يحتاج سيرفر.

## النشر على GitHub Pages
1. ارفع الملفات إلى مستودع GitHub
2. من Settings → Pages → اختر Deploy from branch → `main` / `/ (root)`
3. سيكون الرابط: `https://USERNAME.github.io/REPO/`
